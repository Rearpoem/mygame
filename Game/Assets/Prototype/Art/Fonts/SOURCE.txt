The explicit Prototype/Generate Hub menu or batch method builds a Dynamic
TextMeshPro font asset from this source, enables multiple atlases, and prewarms
characters found in this prototype's C# and JSON files. The original source font
is included by the font asset so additional Chinese text can populate at run time.
No Windows system font is used or redistributed.
